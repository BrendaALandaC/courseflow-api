# courseflow-api
CourseFlow API is a backend portfolio project built with Java and Spring Boot.
It provides course management, participant enrollment, JWT authentication, certificate generation, Excel reports, file handling, and Dockerized deployment.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- MariaDB
- Docker
- Swagger / OpenAPI
- Apache POI
- PDF generation

## Project Status

In development.

## Main Features

- User authentication with JWT
- Role-based access control
- Course management
- Participant management
- Enrollment tracking
- PDF certificates
- Excel reports
- File upload and download
- Basic auditing
